# Cover Letter Templates

This directory contains targeted cover letter templates for different types of construction roles.

## Usage

1. Copy the appropriate template to the root directory as `letter.typ`
2. Customize the bracketed placeholders `[Company Name]`, `[Position Title]`, etc.
3. Compile: `typst compile letter.typ`

## Available Templates

- **senior_pm.typ** - Senior PM roles emphasizing leadership and P&L management
- **lean_construction.typ** - Roles focused on Lean Construction implementation
- **multifamily.typ** - Multifamily/apartment development focused positions

## Creating Custom Letters

For specific applications, copy one of the base templates and save as:
`letters/YYYY-MM-DD_company-name.typ`

Example: `letters/2025-01-15_turner-construction.typ`

This keeps all applications organized and version-controlled.
