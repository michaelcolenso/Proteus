## Status Key
- **Applied** - Submitted application
- **Phone Screen** - Initial recruiter call scheduled/completed
- **Interview 1** - First round interview scheduled/completed
- **Interview 2+** - Second/final round interviews
- **Offer** - Offer received, pending decision
- **Accepted** - Offer accepted (congratulations!)
- **Rejected** - Not moving forward
- **Withdrawn** - You withdrew application

## CV Variant Key
- `cv_senior_pm` - Senior PM emphasis
- `cv_superintendent` - Field operations emphasis
- `cv_estimator` - Preconstruction emphasis
- `cv_exec_summary` - One-page summary
- `cv` - Standard full CV

## Cover Letter Key
- `senior_pm` - Senior PM template

- `lean_construction` - Lean/process improvement template

## Application Template

When creating individual application files (`YYYY-MM-DD_company-name.md`), use this structure:

```markdown
# Company Name - Position Title

**Date Applied**: YYYY-MM-DD
**Job Posting URL**: [URL]
**CV Variant Used**: cv_senior_pm
**Cover Letter**: senior_pm (customized)

## Company Research
- [Key facts about company]
- [Recent projects]
- [Company values/culture]
- [Why you're interested]

## Job Requirements Alignment
- Requirement 1: [How you meet it]
- Requirement 2: [How you meet it]
- Key qualification: [Your experience]

## Key Talking Points
1. [Relevant project example]
2. [Relevant skill/achievement]
3. [Why interested in this company]

## Application Customizations
- CV: [What you emphasized/adjusted]
- Cover Letter: [Specific customizations made]

## Timeline
- Applied: YYYY-MM-DD
- Follow-up: YYYY-MM-DD
- Response: YYYY-MM-DD

## Notes
[Any additional notes, contacts, research]
```
