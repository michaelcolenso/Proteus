## Design Context

### Users
This is a personal job-search toolkit for Michael Colenso, a construction project manager preparing, tracking, and tailoring job applications. The main context is a focused desktop workflow using shell commands, Markdown reports, Typst documents, and version-controlled application notes.

### Brand Personality
Precise, professional, and practical. The experience should feel calm and trustworthy, with clear next steps and no decorative flourish that slows down application work.

### Aesthetic Direction
For CLI, reports, and docs, favor readable Markdown, concise labels, predictable paths, and explicit status summaries. Browser UI, when present, should stay clean and workmanlike, supporting fast review and decision-making rather than marketing-style presentation.

### Design Principles
- Make the next action obvious from every generated report or command output.
- Keep terminology consistent across CLI, reports, docs, and tracker files.
- Prefer transparent state and file paths so generated artifacts are easy to inspect and clean.
- Preserve a polished daily workflow: low friction, predictable output, and no surprising git noise.
- Keep copy direct and job-search focused.
